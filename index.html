Method & source. Live read-only from the iBOS DWH (mes.tblOeeProdWasteHeaderArc, RowArc, tblNPTHeaderArc, RowArc, tblProductionPlanningArc). Formulas follow the OEE dashboard skill: Capacity = Σ(capacity/hr × shift min ÷ 60) · Yield = Good ÷ Production · Wastage = Σ waste rows ÷ Production · NPT% = NPT loss minutes (Electrical 456 + Mechanical 457) ÷ Available minutes · Availability = (Available − NPT) ÷ (Shift − Planned DT) · Performance = SMV × (Production ÷ Available) · Quality = (Production − Waste) ÷ Production · OEE = A × P × Q × 100 (shown only when inputs are valid, so idle/zero-output rows never display 100%). MTBF = (Shift min ÷ 60) ÷ breakdowns · MTTR = (NPT min ÷ 60) ÷ breakdowns. Machine OEE tile = average of machines having a valid OEE. When more than one UoM is in view, quantity totals (production/target/capacity) mix units and are not additive — pick a UoM (or a machine) for comparable figures. Wastage Tgt reads the header column which is typically 0 in this data (a known source-field issue).
5S Score & Kaizen are read live from each SBU's public Google Sheet CSV (lib/sheets.js → SHEET_CONFIG): 5S = average Final Score on the latest date in range (target 70%), Kaizen = IC cards created within the range (target 10). No sheet exists for ARMCL / ABSL / ALEL.
Schedule Maintenance (per schedule-maintenance-dashboard-guide.md) reads ast.tblPreventiveMaintenanceSchedule via the enterprise-api-gateway, scoped to each BU by the strScheduleNo prefix (PSM-ACCL, PSM-APFIL, …) because the table has no BU column. Close Rate = Closed ÷ Total; “Closed” needs intScheduleMaintenanceStatusId, which the API does not expose yet, so only totals show until the gateway adds it (guide §5). ABSL/ARL have no schedules.
Production Plan Variance reads mes.tblProductionPlanVarianceIssueArc (DWH, read-only), de-duplicated per strProductionPlanCode (each plan repeats once per logged issue). Difference = output − planned · Progress = output ÷ planned · Variance Flagged = plans running short · Issues Missing = short plans with no issue logged.
